# ETHARA TEAM TASK MANAGER

Enterprise role-based team productivity platform for managing projects, tasks, attendance, and analytics. Built with **FastAPI + SQLite** (backend) and **React 18 + TypeScript + Vite + Tailwind CSS** (frontend).

> ⚡ One command to run locally · One push to deploy.

# 📌 Features

- Role-based Authentication (Admin / Member)
- Team Dashboard
- Attendance Tracking
- Project Management
- Task Management
- Activity Logs
- Analytics Overview
- Responsive Enterprise UI
- Secure API Integration
- Dark Modern UI Design
